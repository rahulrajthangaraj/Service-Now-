# Import Data Using Transform Maps (Spreadsheet)

## 📌 Project Overview
This project demonstrates how to import spreadsheet data into ServiceNow using Import Sets and Transform Maps. It simplifies bulk data import and ensures accurate mapping between source and target fields.

## 🎯 Objective
To import employee data from an Excel spreadsheet into ServiceNow using Import Sets and Transform Maps.

## 🛠️ Technologies Used
- ServiceNow
- Microsoft Excel / CSV
- Import Sets
- Transform Maps

## ⚙️ Project Workflow
1. Prepare employee data in an Excel spreadsheet.
2. Upload the spreadsheet into ServiceNow.
3. Create an Import Set Table.
4. Create a Transform Map.
5. Map source fields to target fields.
6. Execute the Transform Map.
7. Verify the imported records in the target table.

## ✨ Key Features
- Spreadsheet data import
- Automatic field mapping
- Bulk record processing
- Data transformation
- Target table record verification
